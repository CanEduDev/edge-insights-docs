# Edge Insights

Edge Insights captures CAN bus traffic, decodes it against your DBC files,
and surfaces timing, congestion, and error anomalies through a local web
portal and Grafana dashboards. It runs on Windows and Linux PCs and on
embedded Linux devices (x86_64 and arm64), right next to the bus you're
monitoring.

Whether you're validating a prototype network or keeping an eye on a bus in
the field, Edge Insights turns raw CAN frames into signals and insights you
can act on — no cloud round-trip required.
